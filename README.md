# 幻兽群岛 · 精灵大师之旅

一款纯前端实现的 2D 俯视视角幻兽收集养成游戏。卡通风格，Canvas 实时渲染，无需后端、无需构建，浏览器直接打开 `index.html` 即可游玩，进度自动保存在 localStorage。

## 运行

直接双击 `index.html`，或在目录下起一个静态服务：

```powershell
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 操作

- 鼠标点击地块自动寻路；键盘 `WASD` / 方向键移动
- 走到 NPC、资源点、传送门旁边，点击自身或按 `E` / 空格 互动
- 点击底部主战幻兽切换出战跟随（10 秒冷却）

## 核心玩法

### 1. 捕捉与收集
- 主世界有 5 座岛屿：初心岛 → 碧波滩 → 炽焰山 → 疾风原 → 神魔圣域（按训练师等级解锁，可由传送门或地图面板前往）
- 触碰野生幻兽可选择「直接捕捉」或「发起战斗」；对方生命越低、精灵球越高级，成功率越高；诱兽果 +25%
- 地图上的神秘幻兽蛋拾取后靠行走步数孵化，岛屿阶位越高蛋池越稀有

### 2. 元素克制（克制方伤害 +10%）
- 水 → 火 → 风 → 水（循环克制）
- 神 与 魔 相互克制，且神、魔都克制水/火/风三系

### 3. 等级 / 升星 / 进化
- 等级上限随星级提升：1~5 星对应 10 / 20 / 30 / 40 / 60 级
- 升星消耗同品质碎片 + 金币，或直接消耗同名幻兽；技能星级（1-3）解锁更强技能
- 幻兽达到等级（16 / 34）自动可进化，如 水滴仔 → 波纹兽 → 沧海龙皇

### 4. 品质与资质
- 品质 N < R < SR < SSR < UR，决定基础属性倍率
- 资质 D/C/B/A/S/SS 直接百分比加成攻击与防御；升星解锁 A（2星）、S（3星）、SS（4星）洗髓区间，洗髓可刷新资质，资质在升星时继承

### 5. 主战 / 助阵
- 主战位 3 个，场景只跟随 1 只，战斗中可轮换
- 辅战位 3 个（训练师 Lv.5 / 15 / 30 消耗钻石解锁），不参战但按辅战位等级（Lv1=6% → Lv10=24%）把自身属性叠加给主战幻兽

## 界面布局

- 左上：训练师头像、出战幻兽生命/经验条、战力与货币
- 右上：带迷雾的小地图（营地、传送门、野生刷新点、当前位置）
- 底部：6 格队伍栏（3 主战 + 3 辅战）
- 右下：背包 / 队伍 / 孵蛋 / 地图 / 帮助
- 营地 NPC：护士（免费全队治疗）、旅行商人（精灵球/药剂）、岛屿长老（情报）

## 文件结构

- `index.html`：入口与界面骨架
- `css/style.css`：卡通 HUD / 模态 / 战斗样式
- `js/data.js`：元素克制、技能、25 种幻兽、道具、岛屿与生成配置
- `js/state.js`：宠物创建、属性公式、经验/升星/洗髓/进化、存档
- `js/world.js`：地图生成、BFS 寻路、移动、Canvas 渲染、迷雾、小地图
- `js/battle.js`：回合战斗、伤害公式、捕捉判定、AI、奖励结算
- `js/ui.js`：所有面板（背包/队伍/孵蛋/地图/商店/战斗/帮助）
- `js/main.js`：游戏主循环、输入、自动存档与孵化检查
